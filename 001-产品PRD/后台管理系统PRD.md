# MathSigma 后台管理系统 · 产品 PRD

> 版本：v1.0 ｜ 日期：2026-11-05 ｜ 状态：评审中
>
> **前提约束：禁止修改数据库以及数据库的表结构。** 本 PRD 中所有功能均基于现有
> `mathsigma` 库的 6 张表实现：`user` / `kp` / `question` / `attempt` / `mastery_scores` / `setting`。

## 一、背景与目标

现有学习平台（frontend）已上线：注册登录、知识点学习、练习答题、AI 答疑。
缺少一个供教师/运营使用的后台管理系统，用于查看注册用户、学习记录、题库质量等运营数据。

目标：为教师和管理员提供一个 Web 后台，**只读查看 + 题库维护**，不改动任何表结构。

## 二、用户与角色

| 角色 | 说明 | 入口 |
|------|------|------|
| 管理员 | 教师/运营，可看全部数据，可维护题库 | `/admin.html`，需管理令牌（`x-admin-token`） |
| 学生 | 不进入后台 | — |

## 三、功能点列表

### 1. 数据总览（Dashboard）
- [x] 题库总量、知识点数量、注册用户数、答题记录总数
- [x] 题目按知识点 / 难度 / 来源分布
- [x] 重复题目（哈希碰撞）统计

### 2. 用户管理（只读）
- [x] 注册用户列表：用户名、年级、教材版本、昵称、注册时间
- [x] 按"体验账号每日清理"规则展示清理状态，支持手动重置体验数据
- [ ] 用户详情：单个用户最近 N 条答题记录、每个知识点的掌握度（读 `mastery_scores`）

### 3. 答题记录（只读）
- [x] 最近答题记录列表：用户、题目、知识点、难度档、对错、用时、时间
- [ ] 按用户名 / 知识点 / 时间段筛选
- [ ] 导出 CSV

### 4. 题库管理（可写，仅限 question 表业务字段）
- [x] 题目增删改查（题干、选项、答案、解析、知识点、难度档）
- [x] 批量导入 / 导出（JSON、CSV），自动去重（内容哈希）
- [ ] 难度值（1-5）批量校准视图：按知识点查看难度分布

### 5. 自适应监控（只读）
- [x] 学生 × 知识点掌握度查询（`mastery_scores`，0~1 分值）
- [x] 按掌握度推算的目标难度预览（`GET /api/recommend`）
- [ ] 全班掌握度热力图（知识点 × 学生矩阵）

### 6. 系统配置
- [x] DeepSeek API Key / 模型 / BaseURL 配置（存 `setting`）
- [x] 服务健康检查（`GET /api/health`）

## 四、接口清单（不涉及任何 DDL）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | 服务与数据库状态 |
| `/api/stats` | GET | 总览统计 |
| `/api/kp` | GET | 知识点列表 |
| `/api/questions` | GET/POST | 题库查询 / 新增 |
| `/api/questions/:id` | PUT/DELETE | 题目修改 / 删除 |
| `/api/attempts` | GET/POST | 答题记录查询 / 上报（联动掌握度） |
| `/api/mastery` | GET | 学生×知识点掌握度 |
| `/api/recommend` | GET | 按掌握度动态选题 |
| `/api/register` `/api/login` `/api/me` | POST/GET | 后端认证（密码加盐哈希） |
| `/api/users` | GET | 注册用户列表（需令牌） |
| `/api/import` `/api/export` | POST/GET | 题库导入导出 |
| `/api/ai/key` `/api/ai/chat` | POST | AI 配置与代理 |

## 五、非功能要求

- 管理接口必须校验 `x-admin-token`；未配置令牌时仅限本机开发。
- 所有查询接口有分页与条数上限，避免全表拖取。
- 不新增/修改/删除任何表与列；业务扩展一律通过现有字段（JSON 文本列）承载。
